Definiciones ampliadas

Gabinete (Case)

Caja física que protege el hardware y guía el flujo de aire.

Frecuencia: 3–6 meses
Procesador (CPU)

Ejecuta instrucciones y cálculos. Revisar disipador y renovar pasta térmica.

Frecuencia: 6–12 meses
Memoria RAM

Memoria volátil de acceso rápido.

Frecuencia: 6 meses
Disco duro (HDD/SSD)

Almacenamiento de datos. Realizar respaldos periódicos.

Frecuencia: 6 meses
Fuente de poder (PSU)

Entrega voltajes adecuados. Revisar cables y rejillas.

Frecuencia: 6 meses
Puertos USB

Interface universal para periféricos y energía.

Frecuencia: 3–6 meses
BIOS / UEFI

Sistema que inicia el hardware y permite configurar opciones.

Frecuencia: Revisión anual
GPU (Tarjeta gráfica)

Procesa gráficos y video. Revisar ventiladores.

Frecuencia: 6–12 meses
Firewall

Filtra el tráfico de red y bloquea accesos no autorizados.

Frecuencia: Mensual
VPN

Red privada virtual que cifra la conexión y protege la identidad.

Frecuencia: Según uso
Switch

Conecta varios dispositivos en red local.

Frecuencia: Mensual
DNS

Traduce nombres web a direcciones IP.

Frecuencia: Automático
Sistema operativo (SO)

Administra recursos y aplicaciones. Mantener actualizaciones y antivirus activo.

Frecuencia: Mensual
Driver

Permite que el sistema operativo reconozca y use dispositivos.

Frecuencia: Al instalar hardware
Script

Secuencia de comandos que automatiza tareas.

Frecuencia: Según necesidad
Malware

Software malicioso que puede dañar o robar información.

Frecuencia: Activo y actualizado
Ransomware

Malware que bloquea el sistema y exige rescate.

Frecuencia: Prevención activa
Respaldo en la nube

Copia de seguridad automática en servidores remotos.

Frecuencia: Periódico
Backup incremental

Copia de seguridad que guarda solo los cambios recientes.

Frecuencia: Semanal
